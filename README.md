# Свадебная галерея — 25.09.2026

Лёгкий статический сайт-галерея для публикации на **GitHub Pages** (3 раздела: **Загс**, **Банкет часть 1**, **Банкет часть 2**, без папки «Прогулка»).

## Где вставить ссылку на Google Диск для скачивания

Откройте файл `config.js` и вставьте вашу ссылку в поле `downloadAllUrl`:

```js
downloadAllUrl: "https://drive.google.com/drive/folders/ВАША_ССЫЛКА",
```

При желании можно указать и отдельные ссылки для каждой папки в `folderDownloadUrls`.

## Как опубликовать на GitHub Pages

1. Создайте новый репозиторий на GitHub (публичный для бесплатного тарифа GitHub Pages).
2. Загрузите все файлы из этой папки (`index.html`, `styles.css`, `app.js`, `config.js`, `data/`, `media/`).
   * Если загружаете через веб-интерфейс или GitHub Desktop / `git push`, убедитесь, что загрузились все папки.
3. Откройте в репозитории **Settings → Pages**.
4. В разделе **Build and deployment → Source** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
5. Через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.
